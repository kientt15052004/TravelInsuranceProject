# Test Data SQL Script

## Database Structure

### 1. Users Table

CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    fullname VARCHAR(100),
    mail VARCHAR(100),
    dob DATE,
    address VARCHAR(255),
    phone VARCHAR(20),
    cccd VARCHAR(12),
    avatar VARCHAR(255),
    role ENUM('customer', 'staff', 'admin') DEFAULT 'customer',
    cccd_img VARCHAR(255),
    status ENUM('active', 'inactive') DEFAULT 'active'
);

### 2. Products Table

CREATE TABLE products (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(255) NOT NULL,
    img VARCHAR(255),
    type VARCHAR(50),
    description TEXT,
    price DECIMAL(10,2),
    benefit_id INT
);

### 3. Applications Table

CREATE TABLE applications (
    id INT PRIMARY KEY AUTO_INCREMENT,
    purchaser_id INT NOT NULL,
    product_id INT NOT NULL,
    total_price DECIMAL(12,2),
    startDate DATE,
    endDate DATE,
    travelers_quantity INT,
    type VARCHAR(50),
    destination VARCHAR(100),
    FOREIGN KEY (purchaser_id) REFERENCES users(id),
    FOREIGN KEY (product_id) REFERENCES products(id)
);

### 4. Contract Table

CREATE TABLE contract (
    contract_id INT PRIMARY KEY AUTO_INCREMENT,
    application_id INT NOT NULL UNIQUE,
    contract_status VARCHAR(50),
    description TEXT,
    FOREIGN KEY (application_id) REFERENCES applications(id)
);

### 5. Claims Table

CREATE TABLE claims (
    id INT PRIMARY KEY AUTO_INCREMENT,
    contract_id INT NOT NULL,
    requestDate DATE,
    claim_type VARCHAR(100),
    description TEXT,
    payment_bank VARCHAR(100),
    payment_number VARCHAR(50),
    related_img VARCHAR(255),
    related_file VARCHAR(255),
    claim_status VARCHAR(50),
    FOREIGN KEY (contract_id) REFERENCES contract(contract_id)
);

## Test Data Plan

### 1. Users Table (100 records)

- 80 customers (role='customer')
- 15 staff (role='staff')
- 5 admin (role='admin')
- Status: 70% active, 30% inactive
- Vietnamese names, emails, phones, addresses
- DOB: random từ 1970-2005
- CCCD: 12 digits format
- Username format: cus001-cus080, staff001-staff015, admin001-admin005
- Password: mật khẩu đơn giản cho test (123456)

### 2. Products Table (10 records)

- 5 domestic travel insurance products
- 5 international travel insurance products
- Price range: 500,000 - 5,000,000 VND
- Có descriptions và type rõ ràng

### 3. Applications Table (150 records)

- Chỉ 80 customers có applications
- Phân bố: một số customers có 1 application, một số có 2-3 applications
- product_id: random từ 1-10
- total_price: 500,000 - 10,000,000 VND
- startDate: từ 01/01/2024 đến 31/12/2025
- endDate: 7-30 days sau startDate
- travelers_quantity: 1-5 người
- type: domestic hoặc international (khớp với product)
- destination: Việt Nam, Mỹ, Nhật Bản, Hàn Quốc, Thái Lan, Singapore, Malaysia, Indonesia, Pháp, Úc

### 4. Contract Table (150 records)

- Quan hệ 1-1: Mỗi Application có đúng 1 Contract
- application_id: 1-150 (UNIQUE constraint)
- contract_status phân bố:
  - PENDING: 30 records (20%)
  - APPROVED: 75 records (50%)
  - ACTIVE: 30 records (20%)
  - REJECTED: 15 records (10%)
- description: Mô tả rõ trạng thái và lý do

### 5. Claims Table (60 records)

- Chỉ contracts có status='APPROVED' hoặc 'ACTIVE' (105 contracts → lấy 60 claims, ~57%)
- claim_type:
  - Lost Baggage
  - Medical Emergency
  - Trip Cancellation
  - Accident
  - Flight Delay
  - Theft
- claim_status: PENDING (40%), APPROVED (40%), REJECTED (20%)
- payment_bank: Vietcombank, BIDV, ACB, Techcombank, VietinBank, MB Bank
- payment_number: 12-14 digits
- requestDate: Sau startDate của application, trước endDate
- related_img: claim_img_001.jpg, claim_img_002.jpg, etc.
- related_file: claim_doc_001.pdf, claim_doc_002.pdf, etc.
